# AI and Human Development Workflows Overview

## Purpose
This directory contains actionable workflows defining step-by-step processes for planning, implementing, testing, and reviewing code in various scenarios (e.g., feature additions, legacy migrations, hotfixes, etc.).

## Scope
## Developer User Guides & Prompts

To understand how to apply these workflows in daily development or how to configure AI prompts, refer to the:
- **[Guides Index](../guides/README.md)**: Standard developer onboarding, setup, and troubleshooting documentation.
- **[Prompts Index](../prompts/README.md)**: Pre-configured, copy-and-paste ready AI prompts mapping to these workflows.

## Target Workflows
- **Feature Implementation Workflow**: Steps to go from raw user request to fully tested implementation.
- **Legacy Modernization & Refactoring Workflow**: Safe step-by-step instructions for breaking down monolith or spaghetti code.
- **Security Hotfix Workflow**: Fast yet rigorous workflow for deploying critical security patches.
- **UI Review & Verification Workflow**: Steps to verify and align visual designs with standard guidelines.
