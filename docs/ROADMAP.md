# PromptEngine Roadmap

This roadmap details planned enhancements and feature additions to the PromptEngine platform.

---

## Phase 1: Core Platform Stabilisation (Active)
- Fully wired CLI command suites.
- Cross-platform release packaging and installer scripts.
- GoReleaser pipeline and Homebrew tap integrations.
- Strict filesystem traversal security audits.

---

## Phase 2: Remote Registries & Cloud Sync
- Support fetching playbooks directly from remote repositories via HTTPS/SSH.
- Sync organization coding standards across team environments.
- Offline-first cache syncing with conflict resolution.

---

## Phase 3: Marketplace & Extensibility
- Centralised registry of community technology stack plugins.
- Safe signed plugin verification model.
- One-click installers: `promptengine install plugin-name`.

---

## Phase 4: IDE Integrations
- **VS Code Extension**: Inline standard verification, auto-fixes directly in the editor, and one-click prompt generation.
- **JetBrains Plugin**: WebStorm, IntelliJ, and PhpStorm integrations.
- **LSP Support**: Language Server Protocol implementation mapping markdown standard references.
