# Engineering Decision Guides Overview

## Purpose
This directory contains architectural and design decision trees, options matrices, and trade-off guides to help engineers choose the appropriate technology, pattern, or strategy during implementation.

## Scope
Provides a unified decision-making framework for architectural choices, stack combinations, state management strategies, and caching solutions across all active tech stacks.

## Target Guides
- **Rewrite vs. Refactor Decision tree**: Guides decision-making when dealing with high-risk legacy code.
- **Stack Selection Matrix**: Compares Laravel Monolith vs. decoupled API + frontend stack (Vue/Flutter).
- **State Management Guide**: Decision framework for state management patterns (Zustand/Redux/Pinia/BLoC/Riverpod).
- **Caching & Database Strategy**: Decision grid for optimizing storage systems and caching layers.
