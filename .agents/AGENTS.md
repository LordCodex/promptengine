# Workspace Rules for AI Coding Agents

Every framework-specific or language-specific conventions file (e.g. `php-conventions.md`, `dart-conventions.md`, `vue-components.md`, `nuxt-ssr.md`, etc.) must comply with the following rule:

## Rule: Universal Code Standards Inheritance
1. **Explicit Inheritance**: Every framework/language document must explicitly inherit from the [Universal Coding Standards](file:///Users/kodexkode/Documents/workspace/promptengine/core/05-universal-coding-standards.md).
2. **No Duplication**: Do not duplicate guidance defined in the universal standard unless the framework requires a different or more specific recommendation.
3. **Reference & Extend**: Instead of repeating universal conventions, reference the universal document using relative links and document only the framework-specific implementations, tools, or variations.
