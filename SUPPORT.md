# Support Guidelines

Thank you for using PromptEngine! If you need help, please use the following official support channels:

---

## 1. Documentation & FAQ
Before raising questions, check the following resources:
- [Quick Start Guide](docs/QUICK-START.md)
- [Installation Guide](docs/INSTALL.md)
- [Troubleshooting & Help](docs/FAQ.md)

---

## 2. GitHub Discussions
For general questions, design discussions, integration queries, or sharing custom playbooks:
- Join the community on [GitHub Discussions](https://github.com/LordCodex/promptengine/discussions).

---

## 3. GitHub Issues
To report bugs, performance regression, or request specific CLI features:
- File a structured issue on the [GitHub Issues tracker](https://github.com/LordCodex/promptengine/issues).
- Please search existing issues to avoid raising duplicates.

---

## 4. Security Escalations
- For security-sensitive issues or vulnerabilities, please review our [Security Policy](SECURITY.md) and email **security@promptengine.dev** directly.
