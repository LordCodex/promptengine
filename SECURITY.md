# Security Policy

## Supported Versions

PromptEngine supports security updates for the following active releases:

| Version | Supported |
| --- | --- |
| 1.x.x | Yes (Active) |
| < 1.x.x | No |

---

## Reporting a Vulnerability

We take the security of PromptEngine seriously. If you identify a security vulnerability (such as path traversal, command injection, execution vulnerabilities, or data leakage vectors), please do **not** file a public GitHub issue.

Instead, report the vulnerability by emailing us at **security@promptengine.dev**.

### What to Include
- A descriptive title outlining the vulnerability type.
- Steps to reproduce, including any sample files, manifest setups, or CLI arguments.
- The version of the PromptEngine CLI and Go runtime you tested on.
- Potential impact or exploitation scope.

### Disclosure Timeline
- We will acknowledge receipt of your report within **48 hours**.
- We aim to provide a remediation plan or patch release within **30 days**.
- Public disclosure will be coordinated with the reporter after a patch has been rolled out.
